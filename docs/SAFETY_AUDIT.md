## 2. Safety model as implemented

- **Levels:** GREEN (default), YELLOW, RED, kept in memory only (`session.safetyLevel`). Never stored. **A reload starts at GREEN**, even after RED (by design: per-visit; HANDOFF open item). CLINICAL DECISION.
- **RED → GREEN in the same visit is impossible** (`SET_SAFETY_LEVEL` ignores GREEN). Every RED exit goes to YELLOW. Matches REVIEW.md.
- **Free-text detection:** `safetyCheck()`. Whole-phrase matching after normalization. Results for 60 inputs are in `SAFETY_TEST_MATRIX.md` (generated from the code; a test fails if it drifts).
- **Where text is checked:** anxious "three things", Thought Parking, spiral "own step", "Thank you for ___". **Not checked:** My Plan fields (by design). The code word "own word" is checked, but a flagged word is only refused; no crisis screen opens.
- **Automatic YELLOW:** 2× "I still feel bad", **or 2× a game answered "No" (counts the same, owner decision in `a254bad`)**, or 2× a 9–10 rating (before or after). Counters are per visit.
- **RED blocks flows:** every flow action calls `blockIfRed()`, which returns to the crisis screen.

## 5. Free-text detection (summary; full table in SAFETY_TEST_MATRIX.md)

- **Handled:** all six expected-RED and five expected-YELLOW sentences; capitals, punctuation, extra spaces, line breaks, missing or curly apostrophes, hyphens.
- **Missed (GREEN):** slang ("kms", "unalive myself"), indirect wording ("I don't want to wake up", "I want to disappear", "I'm a burden", "There's no point anymore", goodbye letters), possible overdose ("I took all my pills", "I took too much"), word forms ("suicides", "overdosing", "kill my self", "iwanttodie", "k1ll myself"), every non-English case, and **all harm-to-others sentences** ("I'm going to kill him", "I want to hurt someone", "I am going to shoot someone").
- **False alarms (RED):** educational or about someone else ("learn about suicide prevention", "My friend survived a suicide attempt", "reading about overdose prevention"), negation ("I'm not suicidal", "I would never kill myself"), the past ("I was suicidal years ago…"), and everyday use ("I can't go on the trip this weekend"). YELLOW false alarms: "give up sugar", "trapped in traffic".
- Owner note: a missed crisis is more dangerous than a false alarm, because the crisis screen is safe to show.

## 6. Owner's conservative addition list (Amendment 3), documented, NOT applied

Exactly as given: **"kms," "unalive myself," "don't want to wake up," "took all my pills," "want to disappear."** Each only increases escalation.

**Can the current code support them cleanly?** Yes. They are plain additions to `RED_PHRASES`; normalization already handles the apostrophe in "don't" (it matches "dont" too). Effects to expect (computed in a sandbox, see the matrix):

- All five confirmed false negatives become RED.
- New false alarms: "I ran 5 kms today", "I took all my pills this morning like the doctor said", "I want to disappear into a good book".
- Not covered by the list: "unaliving myself", "dont wanna wake up", "never wake up" (only the exact phrase "don't want to wake up" matches).
- After applying: run `npm run review` (REVIEW.md lists every phrase) and `npm run safety-audit`; existing tests need no change (none assert these inputs are GREEN).

**Reviewer suggestions (for the owner to decide; not part of the list above):**
- "took too much" and "took too many" (possible overdose; currently GREEN).
- "unaliving myself", "dont wanna live" / "don't wanna be here".
- Harm to others ("kill him/her/them", "hurt someone") needs a **routing** decision, not just more phrases: should it open the same crisis screen (whose danger question already asks about "someone else"), or something different?

## 7. Violence / harm to others: CLINICAL DECISION

The danger question asks about "hurting yourself **or someone else**", and the full crisis screen offers 911 "if someone else is in danger". But all 23 RED phrases are about the self: every harm-to-others sentence tested returns GREEN, so the crisis screen never opens from typed text about others.

## 8. Zags (CLINICIAN REVIEW REQUIRED)

Exact current wording:

- First line, every session: **"Hi, I'm Zags. I'm not a person, just a little guide. I can stay with you for a few minutes."**
- Under every Zags screen: **"Zags is a scripted guide, not a person and not AI."**
- Connect: **"Stay with Zags for a few minutes"** / **"Until someone calls back"**
- Breathing: "You don't have to say anything. Just breathe with me."
- A bit better: "I'm glad. Want to let someone know how you're doing?"

Inconsistencies to review:
1. "I can stay with you" and "Stay with Zags… until someone calls back" suggest companionship or waiting together, next to "not a person". Possible conflict with "must not imply human companionship, dependency, relationship, or replacement for human support".
2. "Until someone calls back" assumes a callback is coming.
3. "I'm glad" expresses a feeling from a scripted guide (mild).
4. **Zags sessions do not count toward Human First** (only "Something else" and finished check-ins do). Zags ends at a person or 988 every time, but repeated Zags sessions never trigger the "Would talking to a person help more…" prompt.

Owner's candidates (Amendment 5, **not applied**):
- "I can stay with you for a few minutes." → "I can guide you through the next few minutes."
- "Stay with Zags for a few minutes — Until someone calls back" → "Calm down with Zags while you wait to hear back."

Rules checked against the code: scripted (`ZAGS_LINES`), says "not a person" first, no names or memory, no pressure to stay ("Not right now" and close always), RED stops Zags, at most two breathing rounds, voice off by default and stops on any tap, "Worse" opens the crisis screen and saves nothing. **On hold and not in the app:** Snuggle Zags, Zags listens, Safe place (no code present).

## 9. Human First

Offers Call someone / Text someone / Be around people / Not right now. **Gap:** Zags and the engine's next suggestions continue after "Not right now"; Zags does not count (see §8.4).
