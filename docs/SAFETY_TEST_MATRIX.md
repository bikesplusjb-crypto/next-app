## Where free text is checked today

- Anxious flow, "three things" fields (each line checked; RED stops at the first RED line).
- Thought Parking (each line; RED creates no cards).
- Spiral "my own next step".
- "Do something kind" → "Thank you for ___".
- Code word "my own word": checked, but a flagged word is only refused (no crisis screen), because it is a My Plan field.
- **Not checked (by design, "plan fields are exempt"):** every My Plan field, including the time and distance plan.
